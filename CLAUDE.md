# farfalle / «Ксюшный мир (заметки)» — контекст проекта

Личный мини-сайт с заметками (раньше назывались «письма»). Чистый HTML/CSS/JS,
без фреймворков и сборки. Автор — Ксюша, общаемся по-русски.

## Адреса и деплой
- Прод: https://kseniaLapushka.github.io/letters/ (адрес решено не менять)
- Репозиторий: https://github.com/KseniaLapushka/letters, ветка `main`
- GitHub Pages: ветка `main`, папка `/ (root)`, билда нет — прод обновляется
  сам после `git push`. Пуш по SSH (ключ уже настроен на этом компьютере).
- Сайт полностью отдельный: никакой связи с репозиторием `phylosophie`
  (конспекты на MkDocs) — это решение пользовательницы, не смешивать.
- Локально: `python3 -m http.server 8081` из корня, открыть http://localhost:8081/
- `gh` CLI установлен, но не авторизован (для пушей не нужен).

## Структура
- `index.html` — главная: hero на весь экран, текст-био, сетка карточек
- `letter.html` — страница заметки, нужная берётся из `?id=`
- `letters.json` — единственный источник данных: `id`, `title`, `date`,
  `color` (сейчас нигде не используется), `excerpt`, необязательный `cover`
  (картинка «внутри конверта»), `content` (блоки `text` / `image`)
- `style.css`, `script.js`; `images/`; `type/` (шрифты)
- Новая заметка = новый объект в `letters.json`, HTML/JS трогать не нужно.

## Дизайн: что решено
Тексты: все предложения с большой буквы; слово «письмо» везде заменено на
«заметка» (кроме текста в `letters.json` у заметки 001, где она сама так
продиктовала).

Шрифты (локальные, `type/`): **Druk Cyr Medium** — заголовки (hero и
заголовки карточек, uppercase); **Monotype Corsiva** — «(заметки)» в hero и
даты на карточках. В Corsiva только одно начертание — «тоньше» сделать
нельзя, тень у «(заметки)» убрана по её просьбе. Основной текст — системный
sans; текст заметки на странице — Helvetica Neue.

Главная:
- hero = `100vh`, картинка `images/home-bg.png` с отступом 10px от края
  экрана, скругление 2px, **без блюра**
- внизу hero — полосатое затухание в белый (`.hero__fade`,
  `repeating-linear-gradient` + маска)
- по центру «КСЮШНЫЙ МИР» + рядом «(заметки)», белые
- карточки появляются при скролле: 2 колонки (1 на мобильном ≤560px),
  фон `#fafaf9`, радиус 2px, без рамки/обводки/тени; порядок внутри —
  заголовок, превью (sans, weight 300, серый), дата снизу (отступ 42px)
- цвет текста везде `#210038`

Страница заметки:
- фон — бумажная текстура `images/letter-bg.avif` (тайлится)
- текст в белом блоке с тонкой светлой рамкой, радиус 2px
- конверт внутри блока над текстом: `images/envelope.jpg` + фото `cover`,
  обрезанное `clip-path` по проёму клапана
  (`polygon(17% 31%, 84% 31%, 84% 48%, 47% 65%, 17% 48%)`), ширина 255px;
  без `cover` конверта нет

## Что пробовали и отменили (не возвращать без просьбы)
- блюр сверху фона (`filter: blur` и `backdrop-filter`), тёмный scrim
- стеклянная рамка-«кольцо» у карточек, градиентная белая обводка, тени
- точка-индикатор цвета на карточке, шрифты Caveat / Inter Tight / Playfair
- `images/home-bg-frame.png` (винтажная цветочная рамка) как фон — не
  понравилось, файл остался в `images/`, не используется
- сайт внутри `phylosophie/docs/letters` (через MkDocs)

## Открытые вопросы
- Не проверено, как выглядит страница при прокрутке до самого низа:
  на одном скриншоте внизу появилась полоса фона с полосками — неясно, баг
  вёрстки или сбой скриншота. Проверить в обычном браузере.
- Шрифты Druk и Monotype Corsiva лежат в публичном репозитории и отдаются
  сайтом — если лицензия платная, нужно проверить, разрешено ли так.
- `color` в `letters.json` пока ничего не делает; `cover` у заметки 001
  указывает на тестовую картинку `images/home-bg.png`; `images/001-1.jpg`
  и `002-1.jpg` не существуют (заглушки).
- В `images/` лежат два лишних PNG из чата (не коммитить).
