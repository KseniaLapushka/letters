# farfalle — мини-сайт с письмами

Отдельный мини-сайт внутри репозитория `phylosophie`. Свой HTML/CSS/JS,
не связан со стилями/навигацией основного сайта (конспектов на MkDocs).

Живёт в `docs/letters/` — то есть внутри той же папки, из которой MkDocs
собирает сайт (`docs_dir` по умолчанию), поэтому попадает в общий деплой
на GitHub Pages автоматически, при этом:
- не участвует в навигации/поиске MkDocs — там учитываются только `.md`
  файлы, а `letters/` — обычная папка со статикой, которую MkDocs просто
  копирует в сборку как есть;
- открывается отдельным URL: `https://kseniaLapushka.github.io/phylosophie/letters/`.

## Структура

- `index.html` — главная: заголовок, короткий текст о себе, список писем
- `letter.html` — шаблон страницы письма (какое письмо показать — определяется
  параметром `?id=` в URL, см. `letter.html?id=001`)
- `letters.json` — единственное место, где хранятся все письма
- `images/` — картинки для писем
- `style.css`, `script.js`

## Как добавить новое письмо

Ничего не нужно трогать в HTML/JS — только `letters.json`. Добавь новый
объект в массив:

```json
{
  "id": "004",
  "title": "Заметка #4",
  "date": "2026-09-01",
  "color": "#f3d9d9",
  "excerpt": "Короткое превью для карточки на главной.",
  "content": [
    { "type": "text", "text": "Текст письма\n\nПустая строка — новый абзац" },
    { "type": "image", "src": "images/004-1.jpg", "alt": "" },
    { "type": "text", "text": "Текст после картинки" }
  ]
}
```

- `id` — уникальная строка, используется в ссылке `letter.html?id=...`
- `color` — фиксированный цвет фона именно этой страницы письма (hex)
- `content` — массив блоков `text`/`image` в том порядке, в котором они должны
  идти на странице
- картинки кладутся в `images/` рядом

## Локальный запуск

Из корня репозитория `phylosophie`: `python3 -m http.server 8081 --directory docs`,
затем открыть `http://localhost:8081/letters/`.
