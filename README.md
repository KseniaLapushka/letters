# farfalle — мини-сайт с письмами

Отдельный самостоятельный репозиторий и сайт — не связан ни с чем другим
(в частности, не имеет отношения к репозиторию `phylosophie` с конспектами).
Чистый HTML/CSS/JS, без фреймворков и сборки.

- Прод: **https://kseniaLapushka.github.io/letters/**
- Деплой: GitHub Pages, ветка `main`, папка `/ (root)` — включается в
  Settings → Pages, отдельного билд-шага не требуется, публикуется сразу
  после пуша в `main`.

## Структура

- `index.html` — главная: заголовок, короткий текст о себе, список писем
- `letter.html` — шаблон страницы письма (какое письмо показать — определяется
  параметром `?id=` в URL, см. `letter.html?id=001`)
- `letters.json` — единственное место, где хранятся все письма
- `images/` — картинки для писем
- `style.css`, `script.js`

## Как добавить новое письмо

Ничего не нужно трогать в HTML/JS — только `letters.json`. Добавь новый
объект в массив:

```json
{
  "id": "004",
  "title": "Заметка #4",
  "date": "2026-09-01",
  "color": "#f3d9d9",
  "excerpt": "Короткое превью для карточки на главной.",
  "content": [
    { "type": "text", "text": "Текст письма\n\nПустая строка — новый абзац" },
    { "type": "image", "src": "images/004-1.jpg", "alt": "" },
    { "type": "text", "text": "Текст после картинки" }
  ]
}
```

- `id` — уникальная строка, используется в ссылке `letter.html?id=...`
- `color` — акцентный цвет точки у карточки на главной (hex)
- `cover` — необязательное поле: картинка, которая появится "внутри
  конверта" перед текстом письма (см. `.letter__envelope` в `style.css`)
- `content` — массив блоков `text`/`image` в том порядке, в котором они должны
  идти на странице
- картинки кладутся в `images/` рядом

## Локальный запуск

Из корня репозитория: `python3 -m http.server 8081`, затем открыть
`http://localhost:8081/`.
